Status: accepted.

## Context

The displacement sweep has no publishable run yet. The 450 km and 600 km east
stops fail the publication gate, and the 300 km west stop was refused.

tracker output. Open on the settled split with its confirmation stamp, then
replay the landfall and the relief's turn from the unedited storms ashore to

supplied before building. The README retains a still for reduced motion.
