        Method

        One edit, three runs, one question.

        Scroll horizontally to see the full diagram.

        Each experiment starts from one analysis of a storm and changes one thing: its starting position, its intensity, the sea surface temperature or a little noise. The model then runs from the same initial time three times: the original forecast, the edited forecast and a control.

        The control keeps the unedited starting state and uses different random seeds. It shows how far the model's own variability moves a forecast. Compare the edited forecast with the control before reading a difference as an effect of the edit.

        For each step the page tests, member by member, whether the fork's distance from the baseline exceeds the control's. The test is a one-sided exact Wilcoxon signed-rank test and needs matched members; the level is .

        A hindcast has no edit. It starts from ERA5 reanalysis, so it shows what the model does from a reconstructed state, not the forecast it would have issued at the time.

        Storms before 2024 are inside the model's training period (data through 2023), so their baseline is not an independent forecast. Each experiment's manifest lists its limits.

        These are precomputed experiments, not live forecasts. They show how the model responds to an edit, not what a real storm would do. The method, the edit limits and how to write your own experiment are in the repository's docs folder.
